# 🎬 Marvel Cinematic Universe Movie Watch Website

A fully responsive and interactive **Marvel Cinematic Universe (MCU) Movie Watching Website** built using **HTML, CSS, and JavaScript**.  
This project allows users to explore MCU movies in timeline order, view movie details, and discover Marvel characters in a clean and engaging interface.

---

## 🚀 Features

- 🎥 Browse all Marvel Cinematic Universe movies
- 🕒 View movies in chronological timeline order
- 🦸 Explore Marvel characters and movie appearances
- 🔍 Search and filter movies
- 📱 Fully responsive design for mobile and desktop
- ⚡ Smooth animations and interactive UI
- 🎨 Modern Marvel-inspired interface

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript (Vanilla JS)** – Dynamic functionality and interactivity
